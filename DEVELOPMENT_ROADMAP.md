The product will be built in vertical slices. A phase is accepted only when its deliverables and acceptance criteria are met; feature completion follows the full definition in `AGENTS.md`.

Phases 2–5 are established, and Phase 5 is **COMPLETE** based on developer-reported Windows Docker health, applied migrations, 55/55 PostgreSQL/Redis tests, and passing browser infrastructure/persistence/lifecycle checks. Codex did not independently run the Windows Docker/browser validation; evidence is recorded in `PROJECT_STATUS.md`. Phase 6 is the next planned phase and has not started.

## Vertical-slice rule

Build one useful journey at a time. The first complete product slice should support an admin-configured classroom and lecture, local sample footage ingestion, asynchronous processing, analytics/report generation, and a teacher viewing that lecture. Do not count a module as complete because code exists; apply the completion criteria in `AGENTS.md`.
