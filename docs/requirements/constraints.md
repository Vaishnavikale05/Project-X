# Constraints

- No video binaries in PostgreSQL.
- No real-time monitoring in MVP.
- No actual college CCTV/NVR/VMS integration during architecture/foundation work.
- Do not assume a particular camera vendor, VMS API, network share, codec, or export mechanism.
- No claims that CV directly measures emotions or psychological states.
- No student identity recognition or face matching in MVP.
- No full application implementation during the blueprint stage.
- Prefer React, Django/DRF, PostgreSQL, Redis/Celery, Python CV tooling, Docker and CI/CD, while deferring exact versions and deployment details.
- Main application remains a modular monolith unless measured needs justify service extraction.
