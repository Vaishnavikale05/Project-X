# Objectives

1. Make post-lecture processing traceable from source file through job, CV output, analytics, and report.
2. Give teachers timely, comprehensible classroom-level summaries with clear data coverage and caveats.
3. Keep media infrastructure replaceable through source and storage interfaces.
4. Enforce institution and object-level access, minimize identifiable data, and avoid unsupported psychological claims.
5. Build the system in tested vertical slices with explicit acceptance criteria.

Success measures and operational SLOs are open decisions; do not invent numeric targets before workload, hardware, and stakeholder needs are known.
